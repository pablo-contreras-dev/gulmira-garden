# Gülmira — A Little Digital Garden ✿

An interactive botanical frontend experience created as a personal digital gift for Gülmira.

## Features
- Handcrafted programmatic SVG Daisy & Bouquet illustrations
- Organic blooming animations with natural physics and gentle wind sway
- Peaceful ambient music synthesizer (Web Audio API)
- Mobile-first responsiveness with touch interactions (sparkle pulse & chimes)
- Discreet Turkish secret note keepsake with luxury digital stationery aesthetic

## Tech Stack
- React + Vite
- Tailwind CSS
- Web Audio API
- Lucide React

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
